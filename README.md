# My Portfolio

## Project Description

My Portfolio is an interactive personal website developed using HTML, CSS, and JavaScript. It introduces me as a Computer Science student, showcases my academic projects, and provides interactive features for visitors.

The website includes three main sections: About Me, Projects, and Contact.

## Main Features

- **About Me:** Personal introduction and inspirational quotes fetched from an external API.
- **Projects:** Displays Daleel KFUPM and File System Simulation projects.
- **Project Search and Sorting:** Allows visitors to search for projects and sort them alphabetically.
- **Contact Form:** Validates required fields and email format before displaying feedback.
- **Visit Timer:** Tracks how long a visitor stays on the website.
- **Coding Level Selector:** Displays different messages for Beginner and Advanced visitors.
- **Dark Mode:** Allows visitors to switch between light and dark themes.
- **Visitor Name:** Saves and displays a visitor's name using localStorage.
- **State Management:** Remembers visitor names and theme preferences.
- **Responsive Design:** Adjusts the layout for different screen sizes.

## Technologies Used

- HTML
- CSS
- JavaScript
- External Quotes API
- localStorage

## Setup Instructions

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click `index.html` and select **Open with Live Server**.
5. The portfolio will open in your browser.

No additional packages are required.

**Note:** An internet connection is needed to fetch quotes from the external API.
